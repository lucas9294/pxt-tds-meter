# 0.3.0 簡化版

主要積木只有：設定 TDS 腳位、量度 TDS ppm（溫度參考預設25°C）、TDS 原始數據 ADC。原始數據積木會重新取31個樣本並回傳中位數（0–1023），約需1.25秒；可放入顯示數字或串列輸出。參考溫度可填另一水溫 sensor 的讀數，範圍0–55°C；本 extension 不會自行測溫。錯誤回傳 -1000，可在進階查看狀態。

腳位只提供 P1、P2、P3、P4、P10，不提供 P0。P3/P4/P10 與 LED 點陣共用，選用時自動關閉點陣；請用 USB 串列查看，量測期間不要重新啟用點陣。Robotbit 未引出的腳位須另用適當連接器。

## ADC 如何換算

預設 ADC 滿量程3.3V，訊號還原倍率1（沒有分壓），校準係數 K=1。未校準也可取得估算值，但不會被標記為已校準。

V = ADC × 3.3 / 1023 × 訊號還原倍率

EC25 = (133.42 × V³ − 255.86 × V² + 857.39 × V) × K / [1 + 0.02 × (水溫 − 25)]

TDS = EC25 × 0.5，單位 ppm。

MH-A11A 的專屬規格尚未確認；上述沿用既有 SEN0244 類型經驗公式，不能保證適合所有同名板。25°C 是假設水溫，不是自動測得；要分析實際準確度，須以已知標準液比較。沒有提供實際 ADC、水溫及標準液濃度，不能從本次修改判定量測誤差。保留原有2.3V及1000ppm範圍限制、訊號波動檢查，超限不會強行截成有效數字。

若實際加了二分之一分壓，請在進階 configureADC 設還原倍率2；不要把 pH 模組的接法或5V供電要求直接套用到未知TDS板。須確認 AO 不超過 micro:bit 可承受電壓。舊版所有校準及診斷積木保留於進階；TypeScript setup 使用 TDSAnalogPin。

示範：A 將估算 TDS 輸出至 USB 串列，B 輸出原始 ADC。

# TDS 水質計：micro:bit + Robotbit

版本 0.2.0。中文 MakeCode extension，依使用者提供的 **MH-A11A 配套程式**移植算法，包含 TDS、EC25、單點校準、資料匯出／載入、訊號濾波，以及外部水溫數值輸入（不包含溫度感測器驅動）。

**相容性狀態：算法有資料依據；MH-A11A 電氣規格及量測準確度尚未經原廠文件或實機確認。** 請先按以下分壓接法及校準流程試機。不要把 SEN0244 的規格當成已證實的 MH-A11A 規格。

## 研究結果

2026-10-03 搜尋 MH-A11A、MH A11A、MH-A11 的中英文型號及 TDS 關鍵字，未找到可核實的 MH-A11A 原廠 datasheet／電路圖。搜尋結果有商家以 MH-A11A 名義售賣 TDS 模組，但商品名稱不足以證明它與 SEN0244 電氣等同，也不足以確認製造商。

使用者資料夾只有測試程式及開發專案，沒有手冊。主要依據是：

- `配套测试例程/配套测试例程/Arduino/Test/TDS_TEST/TDS_TEST.ino`：類比輸入、中位濾波及三次式換算；範例把溫度固定為 25°C。
- `Arduino/calibration/GravityTDS.cpp`、`GravityTDS.h`：用 K 係數校準，由電壓求 EC，再補償 EC 到 25°C，TDS = EC25 / 2。
- STM32／51 範例的接線註解使用模組 VCC→5V、GND→GND、AO→ADC。這是配套程式註解，不是 MH-A11A 的最大額定值證明。

上述檔案用作技術資料，不當作使用者對工作流程的指令。本套件重新編寫，沒有包含原廠 Arduino 或 STM32 程式碼。

交叉核對 [DFRobot SEN0244 原廠資料](https://wiki.dfrobot.com/sen0244) 和 [GravityTDS 原廠算法](https://github.com/DFRobot/GravityTDS/blob/master/GravityTDS.cpp)：係數相同，校準版的計算順序也相同。這支持「軟件算法同類」的推論，**不能證明兩塊硬件相同**。

## 接線：MH-A11A 暫定試機方案

以使用者提供的 5V 模組範例為依據。先核對實物的 VCC／GND／AO 絲印及店家供電資料；如果實物不符，不要通電猜測。**Robotbit 有 5V 電源，不代表 micro:bit IO 可輸入 5V。**

| 接點 | 接法 |
|---|---|
| 模組 VCC／+ | 核實為 5V 模組後，接 Robotbit 標示 5V 的輸出 |
| 模組 GND／− | Robotbit GND，共地 |
| 模組 AO／A／S | 經下方 10kΩ + 10kΩ 分壓接 P1 |
| 模組探頭插座 | TDS 雙針探頭；不是溫度探頭接口 |

```text
模組 AO ── 10kΩ（1%）──┬── Robotbit P1
                       │
                    10kΩ（1%）
                       │
                      GND
```

這是 1/2 分壓：若 AO 為 5V，P1 約 2.5V。先不接 P1，使用萬用錶檢查分壓接點，再接 micro:bit。這不是任意過壓保護，成立條件是模組供電及輸出不超過預定範圍。micro:bit 關機時也要關掉模組，避免向未供電的 IO 輸入電壓。

**附帶 HEX 已設定 `configureADC(3300, 2)`，對應上述分壓。** `2` 是還原倍率，不是電阻值。若日後有可靠資料確認 AO 全範圍均為 0–2.3V，才可考慮直接接 P1，並改成倍率 `1`，然後重新校準。不要只測一杯水便當作確認全範圍。

`3300` 是 ADC 讀值 1023 所代表的估計滿量程電壓 mV，**不是模組 5V 電源**。實際 ADC 比例與 micro:bit 版本、供電及校準有關；可用萬用錶量 P1 的已知穩定電壓，配合原始 ADC 估算 `滿量程mV = VP1(mV) × 1023 / ADC`，最好在多個電壓點驗證。改 ADC 比例會清除舊校準。

普通 IO 用 P1／P2，不要用 Robotbit S1–S8 舵機接口。P0 連蜂鳴器，若改用 P0 需先拔跳線。量測時停止馬達可減少供電雜訊。

## 外部水溫輸入

本版不量水溫，不佔用溫度腳位，也不包含 DS18B20 或其他溫度感測器驅動。請使用另一個水溫 sensor 的擴充量測，確認讀數有效後，在每次 TDS 量測或校準前把攝氏值傳入「輸入外部水溫 °C」。

`tdsMeter.setTemperature(水溫讀數)` 回傳成功與否，接受 0–55°C。無效輸入會令後續換算失敗，直到輸入有效水溫，不會沿用舊溫度。外部 sensor 的斷線／讀值有效性仍須由其擴充判斷；例如故障時回傳 0°C 無法單靠數值區分。

未輸入前預設為 25°C，這是明確假設值，不是量測結果。示範保留 25°C 供試機，接上另一個 sensor 後請在 A 校準、B 量測前更新。輸入值保留至下次設定，不會自動更新或偵測過期。

## 安裝及示範

最快試用：在 [MakeCode](https://makecode.microbit.org/) 首頁選「匯入 → 匯入檔案」，選 `tds-meter-demo.hex`。HEX 內含程式及中文積木；亦可完成正確接線後複製到 MICROBIT 磁碟。

- A：在 **1413µS/cm @25°C 標準液**中，待穩定後校準。顯示勾代表成功，串列輸出校準文字。
- B：量度一次，在燈陣顯示 ppm，串列輸出 ADC、TDS、EC25、所用溫度及狀態。
- A+B：清除校準。

示範預設分壓倍率 2、手動水溫 25°C。不是在標準液中就不要按 A；請先改正實際水溫或傳入另一個 sensor 的新讀數。未校準按 B 會顯示錯誤，仍可查看 ADC。

重用為 extension：將 `pxt-tds-meter` 資料夾內檔案上傳到自己的 GitHub repository **根目錄**，再於 MakeCode「擴展／Extensions」貼 repository 網址。本套件尚未代你發佈 GitHub。ZIP 是原始碼包，不是 HEX；本版已不需要 C++ 溫度驅動。

## 校準步驟及單位

1. 接線、ADC 比例及電源確定後，開機只呼叫一次 `setup(P1)`；然後 `configureADC(3300, 2)`，設定外部水溫數值。
2. 將探頭以去離子水沖洗，放入獨立小杯的新鮮標準液，輕輕攪動除去氣泡，等讀值與溫度穩定。
3. 使用 **EC 校準積木**輸入瓶上「25°C 參考值」，例如 1413µS/cm。本套件使用單點 K 係數校準，不是 pH 的兩點／三點校準。
4. 或使用 TDS 校準積木，輸入 **0.5 制且以 25°C 為參考**的 ppm。1413µS/cm × 0.5 = **706.5ppm**；不能把 1413µS/cm 當 1413ppm 輸入，也不要把標成 0.7 制／442 制的 ppm 直接代入。
5. 最穩妥是在標準液實際為約 25°C 時校準。其他溫度採用固定 2%/°C 近似；實際標準液溫度曲線不同時會有偏差。
6. 校準後清洗並以另一份已知濃度的標準液驗證，尤其 MH-A11A 原廠規格未核實；單點吻合不能證明整條曲線相符。
7. 換成水樣，待穩定，執行「量度一次 TDS 及 EC」，確認狀態正常再讀值。

校準 EC 允許 100–2000µS/cm，TDS 允許 50–1000ppm；K 限定 0.25–4。訊號太低、ADC 飽和、波動大或 K 不合理會拒絕校準，保留舊係數。不要透過強行放寬 K 掩蓋接線／公式錯誤。

## 計算方式及限制

```text
V = ADC / 1023 × ADC滿量程mV / 1000 × 分壓還原倍率
ECraw = 133.42 × V³ − 255.86 × V² + 857.39 × V
EC25 = ECraw × K / (1 + 0.02 × (T − 25))
TDS（0.5制）= EC25 × 0.5
K = 標準EC25 × (1 + 0.02 × (T校準 − 25)) / ECraw
```

配套的簡單測試版先補償電壓、再代入三次式；校準版先算 EC 再補償。三次式非線性，所以兩者在非 25°C 時不等價。本套件選擇**校準版／DFRobot GravityTDS 函式庫的 EC 補償方式**；不會同時做兩次溫度補償。

採用 31 個樣本、每次間隔 40ms 的中位數，約 1.25 秒；波幅檢查丟掉最高和最低各一點，剩餘波幅大於 15 ADC 計數會回報不穩定。短時間穩定不等於水樣和探頭已達平衡。

目前軟件採保守的 SEN0244 型算法範圍：模組還原電壓不高於 2.3V、EC25 不高於 2000µS/cm、TDS 不高於 1000ppm。**這是本版的使用限制，不是 MH-A11A 的已驗證量程。** 超範圍回報錯誤，不把數值截成 1000 製造正常讀數。

EC 也是由同一類比訊號及經驗式估計，不是另一顆獨立 EC 感測器。TDS 是基於導電度的估算，受離子種類和換算制影響；不能單憑 TDS 判定飲用水是否安全。顯示精細數字不代表相同精度。本機資料不足以給 MH-A11A 承諾精度。

## 積木與錯誤

| API | 用途 |
|---|---|
| `setup` | 設 TDS 腳位並清除校準、ADC 設定及舊讀數，補償溫度回到 25°C |
| `configureADC` | 設 ADC 滿量程及分壓還原倍率；有效更改會清除校準 |
| `setTemperature` | 輸入另一個 sensor 量得的攝氏水溫 |
| `calibrateEC` / `calibrateTDS` | 校準；回傳真／假 |
| `measure` / `readTDS` | 重新量度，後者回傳 ppm |
| `tds` / `ec25` | 取上次 TDS／EC25，不重新量度 |
| `temperatureUsed` | 上次計算實際使用的溫度，可以是人工輸入值 |
| `readRawADC` / `rawADC` / `voltage` | 未校準也能診斷 ADC 和估算電壓；重新讀 ADC 令舊 TDS 失效 |
| `status` / `calibrationStatus` | 分別查看量測、校準操作狀態 |

失敗或尚無結果時，TDS／EC 回傳 **-1000**。讀值前查看狀態：

| 代碼 | 意義 |
|---|---|
| 0 | 正常 |
| 1 | 尚未量度 |
| 2 | 尚未校準 |
| 3 | ADC 飽和或電壓超過算法範圍 |
| 4 | 訊號不穩定 |
| 5 | 校準／載入資料無效 |
| 9 | 超出應用量程 |
| 10 | 設定或腳位錯誤 |

零 ADC 可以來自低導電度，也可以是短路；軟件無法可靠區分。沒有自動探頭斷線識別保證，必須用標準液做功能檢查。

## 保存校準與同時使用 pH

校準存在 RAM，斷電消失。取得 `exportCalibration()` 的文字後，放回開機程式，順序為 `setup` → `configureADC` → `restoreCalibration(文字)`，再輸入外部水溫。載入時 ADC 滿量程與倍率必須與文字相同；錯誤會拒絕載入並保留之前校準。重新上電若程式仍載入舊文字，清除 RAM 不會永久刪除它，需修改程式再下載。

更換探頭、供電、電阻或模組後重新校準，不共用不同實物的 K。

本版只佔用一個類比腳。若與 pH 擴充一起使用，可將 pH 設為 P1、TDS 設為 P2，另外安排水溫 sensor 的腳位。水溫的讀取及錯誤判斷由該 sensor 的擴充負責。兩個非隔離水質電極同時浸入同一水樣的電氣互擾仍須實測，建議先逐一量測。

### 由 0.1.0 升級

`setup(P1, P2)` 改為 `setup(P1)`；`useManualTemperature(t)` 改為 `setTemperature(t)`。刪除舊的自動水溫／讀水溫／水溫狀態積木，改用獨立 sensor 的擴充。校準文字格式 TDS1 保持相容。請使用本版 HEX 或更新後重建舊積木；本版不再附帶 onewire.cpp。
